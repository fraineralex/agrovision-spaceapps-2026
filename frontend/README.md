# Frontend propuesto

Aún no se decide framework. Propuesta para el MVP: React + Leaflet, interfaz adaptable a teléfono con mapa/pin, selector de prioridad, resumen climático y tres tarjetas de rotación con evidencia, riesgos y escala espacial.

Consumir `GET /health` y `GET /climate` del backend. Mantener una ruta de demostración que funcione con datos cacheados. No dibujar límites parcelarios como si fueran observaciones de alta resolución. Antes de crear el cliente, acordar componentes y el esquema JSON con backend.
