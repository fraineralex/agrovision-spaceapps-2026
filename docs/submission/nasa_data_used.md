## NASA data with local evidence

**NASA POWER — regional meteorological context.** Provider: NASA Langley Research Center POWER project. [Source](https://power.larc.nasa.gov/); [daily API endpoint](https://power.larc.nasa.gov/api/temporal/daily/point). Method: reanalysis-derived meteorological data, not a station or parcel measurement. The local artifact `data/cache/power_daily_18.8_-71.23_2016-01-01_2025-12-31.csv` contains 3,653 daily records from January 1, 2016 to December 31, 2025 for a regional query point in San Juan. `scripts/fetch_power.py` requests the AG community and T2M, PRECTOTCORR and RH2M. Units are temperature °C, precipitation mm/day and relative humidity %, confirmed by the three-day API verification response now included from main; the original full CSV does not retain its response metadata. The cache has no blank/-999 values in those columns; this check does not establish source accuracy.

Meteorological native grid context is about 0.5° latitude × 0.625° longitude; [NASA POWER technical presentation](https://ntrs.nasa.gov/api/citations/20230015396/downloads/ASA_CSSA_SSSA_Mikovitz.pdf). The downloaded point is a grid query, not a producer location. Planned use is regional temperature/humidity context. PRECTOTCORR is retained in the cache, but the team prioritizes IMERG for rainfall comparison and excludes POWER rainfall from the main precipitation score. Evapotranspiration is not a measured variable in this cache: a FAO-56 estimate would require additional inputs and explicit assumptions. The updated main branch includes `data/cache/power_verification_sample.json`: API v2.10.3, MERRA2/POWER sources, LST daily timing, and explicit units for a three-day cross-check. The remaining full-series download metadata should still be retained. Main documents application integration in `docs/DATA_SOURCES.md`; this market task did not rerun its UI checks. Do not claim a 40-year series was analyzed when the available local cache spans ten years.

**Landsat 8–9 Collection 2 Level-2 — NASA/USGS.** The updated main branch supplies `data/cache/landsat_point_sample.json`: 18 point responses at three synthetic demo-area centers across six 2024 scenes (January 5, April 2, June 13, August 8, September 25 and December 6). Red/NIR/QA values are retained from Microsoft Planetary Computer; 30 m pixels are not parcel averages. See [USGS surface reflectance](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-reflectance) and [DOI 10.5066/P9OGBGM6](https://doi.org/10.5066/P9OGBGM6). Main documents QA masking and reflectance-scaled NDVI in [methodology](../METHODOLOGY.md). Its thresholds are exploratory, not a trained classifier; irrigation/rainfed classification is null. Six scenes do not establish monthly bare-field periods. HLS remains planned and is not the actual input of this sample.

**NASA GIBS context imagery.** Main supplies four original tiles and exact URLs in `data/cache/gibs/manifest.json`: static Blue Marble and dated MODIS Terra NDVI 8-Day / IMERG Precipitation Rate imagery for November 1, 2026. These are cached visualization layers, not numeric rainfall/NDVI values extracted from colors; the IMERG layer does not establish an ingested rainfall time series. See [GIBS API documentation](https://nasa-gibs.github.io/gibs-api-docs/access-basics/) and the [main data-source record](../DATA_SOURCES.md).
