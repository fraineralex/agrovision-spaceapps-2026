## NASA data with local evidence

**NASA POWER — regional meteorological context.** Provider: NASA Langley Research Center POWER project. [Source](https://power.larc.nasa.gov/); [daily API endpoint](https://power.larc.nasa.gov/api/temporal/daily/point). Method: reanalysis-derived meteorological data, not a station or parcel measurement. The local artifact `data/cache/power_daily_18.8_-71.23_2016-01-01_2025-12-31.csv` contains 3,653 daily records from January 1, 2016 to December 31, 2025 for a regional query point in San Juan. `scripts/fetch_power.py` requests the AG community and T2M, PRECTOTCORR and RH2M. Expected units are temperature °C, precipitation mm/day and relative humidity %; the CSV discarded API response metadata, so confirm units/product provenance against the source response before presenting numeric results. The cache has no blank/-999 values in those columns; this check does not establish source accuracy.

Meteorological native grid context is about 0.5° latitude × 0.625° longitude; [NASA POWER technical presentation](https://ntrs.nasa.gov/api/citations/20230015396/downloads/ASA_CSSA_SSSA_Mikovitz.pdf). The downloaded point is a grid query, not a producer location. Planned use is regional temperature/humidity context. PRECTOTCORR is retained in the cache, but the team prioritizes IMERG for rainfall comparison and excludes POWER rainfall from the main precipitation score. Evapotranspiration is not a measured variable in this cache: a FAO-56 estimate would require additional inputs and explicit assumptions. Cache download date, API version metadata and application integration remain pending confirmation. Do not claim a 40-year series was analyzed when the available local cache spans ten years.
