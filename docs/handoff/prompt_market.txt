MODEL / FEATURES (focus on crops of the app: arroz, habichuela, maíz, batata, plátano, guandul, yuca, etc.):
1. Price forecast 3–6 months per crop: seasonal index × trend from wholesale series (simple, explainable: seasonal naive / SARIMA / ETS; report backtest MAPE). Show range, not single number.
2. Oversupply risk ("riesgo de sobreoferta"): Banco Agrícola financed area + siembras growth vs history -> if many are planting the same crop, warn (e.g. plátano 2024 glut).
3. Estimated margin per tarea = forecast price × typical yield − cost (Costos 2019 adjusted by CPI if a source exists; else label as 2019 values).
4. Feed into mercado pillar score and the parcel recommendation ("Conviene sembrar X para cosechar en MES: precio esperado alto, poca competencia").
5. Farmer UI (Spanish, simple): price trend arrow + mini sparkline, "Mejor mes para vender", "Muchos están sembrando esto" warning, margin estimate per tarea. Details/sources in "Ver detalles".
