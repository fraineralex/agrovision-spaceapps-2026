## Riesgos y mitigación

| Riesgo | Mitigación |
|---|---|
| API, cuota o red no disponible | CSV versionado, demo offline, timeout y reintentos acotados. |
| Rejillas no representan parcelas | Mostrar resolución, periodo y advertencia; no afirmar precisión de finca. |
| Nubes o incompatibilidad entre capas | Limitar comparación a escena/ventana válida y posponer integración que no cierre. |
| Recomendación sin validación agrícola | Presentar opciones como escenarios, entrevistar usuario y marcar revisión local pendiente. |
| El envío se demora | Corte interno 6 PM AST; asignar responsable y verificar recibo temprano. |
| Alcance excesivo | Priorizar una región, una serie climática, tres opciones explicables y demo estable. |
